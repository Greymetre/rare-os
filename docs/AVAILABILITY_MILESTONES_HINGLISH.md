# Availability — milestones (17 September 2026)

Base: `07_PHASE_1_LOGIN_AVAILABILITY_PLAN_HINGLISH.md` (sections 6–12), `03_DATA_MODEL.md`, `06_DERIVATION_ENGINES.md`, `02_SCREEN_INVENTORY.md`. Phase 1 plan ke M2–M6 ko chhote, ek-ek karke deliver hone wale milestones mein toda gaya hai. Har milestone tabhi "complete" hoga jab uska exit condition aur tests pass hon.

## Planning defaults (jab tak aap badlein nahi)

- Pilot: **ek company, ek plant**, SEG-D jaisi multi-station line. Baaki segments (SEG-A/B/C) expansion milestone mein.
- Development/test data: **ABC Corp demo company** (prototype seed se). Real company data aane par demo assumptions copy nahi hongi.
- Orders aur stock: **manual entry + CSV import**. Live ERP integration baad mein.
- Calculations deterministic engines se; AI sirf baad mein explanation ke liye. Har commitment (PO approve, schedule publish) insaan karega.
- Scale rules har milestone par: server-side pagination, indexed filters, bade imports/calculations background worker mein, planning results input-version ke saath save.

## Har milestone ke saath compulsory

- **Permissions:** existing catalog ke codes (`masters.*`, `imports.create`, `orders.*`, `inventory.*`, `planning.*`, `purchase.*`, `schedule.publish`, `work_orders.update`, `downtime.create`, `reports.export`) live honge; UI ke saath direct API denial aur cross-company/cross-plant tests.
- **Tests:** engine unit tests (prototype harness assertions port karke), API/permission tests, browser flow `npm run test:regression` mein; `docs/REGRESSION_TESTING_HINGLISH.md` update.
- **Audit:** har create/update/approve/publish audit log mein.
- **Messages:** loading, empty, validation, permission denied aur "missing data" (jaise "Is product ki routing missing hai") har screen par.
- **Aapka manual test guide** milestone complete hone par.

## Kaam karne ka tareeka

Ek milestone local par banega → tests → aapko testing steps → aapka "next" → agla milestone. Push aur live deploy aapke decision ke hisaab se.
